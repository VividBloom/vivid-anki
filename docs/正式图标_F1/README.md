# 瞄一眼 · 正式图标 F1

## 定稿方案

**白色眼睛长在卡片上缘。**

- 卡片顶部直边 **同时是** 眼睛的下眼睑（共用一条轮廓线）
- 上眼睑为向上隆起的弧线，两端与卡片边相接，围成扁杏仁形眼白
- 瞳孔**明显偏右**，形成「正在瞄一眼」的神态
- 右侧一道短弧形速度线，暗示视线快速扫过

**融合逻辑**：A 的识别速度（瞳孔偏右 + 速度线）+ B 的卡片结构（暗示产品形态）。

**品牌色**：#007DFF ｜ **实测**：对比度 152.7，48px 缩小可辨

**所有派生版本都由 `1024_满版原图.png` 用代码生成，不是重新画一遍。**

| 版本 | 生成方式 | 与定稿图的结构相关度 |
|---|---|---|
| `多尺寸/icon_*.png` | 直接缩放 | **1.000** |
| `多尺寸/icon_192_圆角.png` | 缩放 + 圆角遮罩 | 0.925 |
| `深色模式版.png` | 提取图形 mask → 深底 + 发光蓝瞳孔 | 0.890 |

> 瞳孔经代码定位确认：中心 x=546（画布中心 512），偏右 34px，符合「瞄一眼」设计。
