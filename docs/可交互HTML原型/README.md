# 瞄一眼 · 可交互原型

## 打开方式
直接双击 `index.html` 即可（无需服务器、无需联网、无需安装任何依赖）。
建议使用 Chrome / Edge / Safari 最新版。

## 共 40 屏，按七组组织

| 分组 | 数量 | 页面 |
|---|---|---|
| **主流程** | 15 | 引导①②③④ · 今天 · 零复习态 · 复习 · 结算 · 制卡 · AI 预览 · 卡片 · 我的 · 统计 · 回归引导 · 桌面卡片 |
| **空状态** | 3 | 全新用户首页 · 卡片页空态 · 搜索无结果 |
| **错误与异常** | 3 | AI 生成失败 · 导入失败 · 无网络 |
| **权限申请** | 3 | 通知权限 · 相机权限 · 权限被拒引导 |
| **数据流程** | 5 | 导入牌组 · 导入进度 · 导入完成 · 牌组详情 · 提醒设置 |
| **进阶场景** | 9 | 中断恢复 · 撤销反馈 · 卡片编辑 · 关于 · 偏好设置 · 导出备份 · 多端接续 · 实况窗 · 平板布局 |

## 主流程能点什么
| 位置 | 操作 |
|---|---|
| 引导① | 点任一牌组或「我自己有内容」→ 引导② |
| 引导③ | 点时间档位选中 → 「下一步」 |
| 复习页 | 点卡片翻面 → 点四档按钮评分（队列递减，答完自动进结算，连续天数 +1） |
| 首页 | 点「开始复习」；底部 Tab 切换 今天 / 卡片 / 我的 |
| 卡片页 | **点任一牌组 → 牌组详情**；右下角加号 → 制卡页 |
| 制卡页 | 点类型标签切换；点蓝色提示条 → AI 预览；**点拍照/录音 → 相机权限**；**（演示）无网络** |
| AI 预览 | 勾选/取消/删除草稿；**点编辑图标 → 卡片编辑页**；「确认（n）」入库；**「重新生成」→ AI 失败态** |
| 我的 | 「统计与进度」→ 统计；**「每日提醒」→ 提醒设置**；**「导入牌组」→ 导入页**；**「导出与备份」→ 导出页**；**「偏好设置」→ 设置页**；**「关于与反馈」→ 关于页** |
| 导入页 | 点文件或拖放区 → 导入进度；**（演示）导入失败** |
| 桌面卡片 | 点 widget 上「继续复习」→ 复习页；底部三按钮 → **实况窗 / 多端接续 / 平板布局** |
| 复习页底部 | **（演示）中断恢复 / 撤销反馈** |
| 右上角 | 「深色」切深色模式；「重置」回到初始状态 |

## URL 直达
地址栏加 `#页面名` 可跳到该屏，例如 `index.html#widget`、`index.html#errAi`

全部可用值：
```
onb1 onb2 onb3 onb4 home homeDone review done create aipreview
cards my stats back widget
emptyHome emptyCards emptySearch aiLoading skeleton
errAi errImport offline
permNotify permCamera permDenied
importPage importing importOk deck reminder
resume undo cardEdit about settings exportPage handoff liveWindow tablet
```

## 右侧面板
- **流程**：主流程快捷跳转（15 屏）
- **本屏设计要点**：该屏的设计决策与原则说明（每屏 3-5 条）
- **全部页面**：38 屏按六组分类的缩略图导航

## 文件结构
```
index.html    页面骨架
styles.css    全部样式（含深色模式变量、平板宽屏模式）
app.js        38 个页面的渲染 + 交互逻辑
```
三个文件纯原生，无任何依赖，可直接改。
