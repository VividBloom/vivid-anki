## 核心设计原则

1. **接管决策** —— 新手要的不是强大的记忆系统，是替他做决定的东西
2. **永不显示积压** —— 逾期数字是新手弃坑的头号杀手
3. **全程正向措辞** —— 「再来一次」而非「忘记」
4. **AI 草稿制** —— 不确认不入库，错卡混入会摧毁信任
5. **离线优先、导出免费** —— 数据可迁移是信任基础
6. **设置克制** —— 只放 6 个开关，每多一个选项就多一次决策

## 关于名字

**瞄一眼** —— 碎片时间，瞄一眼就够了。

刻意避开「记忆 / 卡片 / 单词」等品类词：一靠品类词，名字就变成说明书，用户看一眼知道干嘛，但记不住、也不会跟别人提起。
